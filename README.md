## 📖 درباره پروژه

**خرج‌یار** یک اپلیکیشن اندرویدی برای مدیریت هوشمند درآمد، هزینه، بودجه و پس‌انداز شخصی است. تمام داده‌ها به صورت **کاملاً آفلاین** و با رعایت حریم خصوصی ذخیره می‌شوند. این اپلیکیشن با بهره‌گیری از هوش مصنوعی Gemini، امکان ثبت سریع تراکنش با زبان طبیعی فارسی و دریافت مشاوره مالی هوشمند را فراهم می‌کند.

## 🆕 تغییرات جدید (v1.1)

### ⌨️ کیبورد فارسی اختصاصی
- **حذف کامل کیبورد سیستم**: تمام فیلدهای متنی اکنون از کیبورد اختصاصی فارسی استفاده می‌کنند
- **کیبورد کامل فارسی**: شامل تمام حروف فارسی، اعداد فارسی و نمادها
- **پشتیبانی از Shift**: تبدیل حروف به بزرگ (Capital)
- **حالت نمادها**: دسترسی به نمادها و علائم خاص
- **پنجره ورودی متن**: باز شدن پنجره جداگانه برای هر فیلد متنی

### 📱 بهبودهای رابط کاربری
- **داشبورد**: حذف دکمه "ثبت تراکنش جدید" بزرگ
- **فیلتر هوشمند**: دکمه‌های "نمایش هزینه‌ها" و "نمایش درآمدها" حالا مستقیماً به تب تراکنش با فیلتر مناسب می‌روند
- **بودجه‌بندی**: انتخاب دسته‌بندی برای بودجه با رابط بهتر
- **صفحه قفل**: کیبورد اختصاصی PIN با نمایش دایره‌ای

### 🔧 اصلاحات فنی
- رفع مشکل تداخل کیبورد با ModalBottomSheet
- بهبود مدیریت focus وIME padding
- اضافه شدن LocalSoftwareKeyboardController برای کنترل بهتر کیبورد

## 🚀 راه‌اندازی

### پیش‌نیازها

- [Android Studio](https://developer.android.com/studio) (Ladybug یا جدیدتر)
- JDK 11+
- SDK اندروید ۳۶ (API 36)
- حداقل SDK اندروید ۲۴ (minSdk)

### مراحل اجرا

1. **کلون کردن پروژه**
   ```bash
   git clone <repository-url>
   ```

2. **باز کردن در Android Studio**
   - Android Studio → Open → انتخاب پوشه پروژه
   - اجازه دهید Gradle Sync کامل شود

3. **تنظیم کلید Gemini API (اختیاری)**
   - یک فایل به نام `.env` در ریشه پروژه بسازید:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```
   - اگر کلید API تنظیم نشود، اپلیکیشن با موتور NLP آفلاین کار می‌کند

4. **اجرای اپلیکیشن**
   - انتخاب دستگاه (امولاتور یا فیزیکی) و کلیک روی ▶️ Run

## 🤖 هوش مصنوعی

## ⌨️ کیبورد اختصاصی فارسی

### ویژگی‌ها:
- **حروف فارسی**: تمام حروف عربی/فارسی با چیدمان استاندارد
- **اعداد فارسی**: ۰۱۲۳۴۵۶۷۸۹
- **نمادها**: @#$%&*+-=<>?/\\
- **Shift**: تبدیل حروف به بزرگ
- **فضا**: دکمه فاصله با برچسب فارسی
- **پاک کردن**: حذف کاراکتر آخر
- **تأیید**: ارسال متن و بستن کیبورد

### نحوه استفاده:
1. روی هر فیلد متنی کلیک کنید
2. پنجره ورودی متن با کیبورد فارسی باز می‌شود
3. متن خود را تایپ کنید
4. دکمه "تأیید" را بزنید
5. متن در فیلد اصلی نمایش داده می‌شود
