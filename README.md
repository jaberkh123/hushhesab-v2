# هوش حساب — نسخه ۲ (اندروید)

اپ حسابداری شخصی فارسی با Kotlin + Jetpack Compose — بازطراحی کامل رابط بر اساس نسخهٔ PWA (hoosha-hesab-v2).

## ظاهر نسخه ۲ (عیناً مثل PWA)
- تم همیشه تیره: پس‌زمینهٔ گرادیان بنفش `#0f0c29 → #302b63 → #24243e` با لهجه‌های طلایی `#ffd700`
- فونت **وزیرمتن** (Vazirmatn) در همه‌جا
- صفحه اول: لوگوی طلایی + تاریخ شمسی، کارت هیرو «موجودی کل حساب‌ها» با گرادیان طلایی، پیش‌نمایش حساب‌ها، شبکهٔ ۲×۲ دکمه‌ها (حساب‌ها طلایی)، دکمهٔ بزرگ «✏️ ثبت هزینه و درآمد»
- دکمه‌های کارت‌مانند نیمه‌شفاف با حاشیه — دقیقاً مثل کارت‌های پنل

## حذف‌شده‌ها نسبت به نسخه ۱ (مطابق PWA)
- قفل PIN (LockScreen + SecurityManager رمزنگاری)
- هوش مصنوعی (Gemini)
- آنبوردینگ و صفحهٔ اجباری «ساخت اولین حساب» (حالت خالی در صفحهٔ اول جایگزین شد)

## حفظ‌شده‌ها
- حساب‌ها با موجودی خودکار، ثبت هزینه/درآمد، فیلتر و جستجوی تراکنش‌ها، CSV، مخفی‌سازی مبالغ، واحد پول
- تبلیغات: بنر «پیشنهاد ما» (سرور شخصی، اسلاگ hushhesab) + ادیوری (بازگشت به برنامه یک‌درمیان، میان‌صفحه‌ای هر ۲۰ کلیک) — دست‌نخورده
